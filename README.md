# Wordle Clone

A fully interactive Wordle clone built using HTML, CSS, and JavaScript.

## Features

- Random word generation using a large word list
- Real word validation
- Wordle-style tile flip animations
- Repeated letter handling
- Color-coded feedback system
- Interactive on-screen keyboard
- Physical keyboard support
- Keyboard color tracking
- Toast-style game messages
- Restart/New Game button

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

1. Clone the repository
2. Open the project folder
3. Open index.html in your browser and run with live server
